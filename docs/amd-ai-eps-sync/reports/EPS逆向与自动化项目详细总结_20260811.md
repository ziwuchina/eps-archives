## 五、关键发现与技术突破

### 5.1 已确认的技术事实

1. **EPS为32位进程（ia32）**，所有地址计算和动态调试按32位处理
2. **IDA-MCP网关端口以11339为准**，历史文档常见11338为错误配置
3. **ExecFunction("script ...") 不是可靠的VBS执行入口**，真实链路走 CSScriptHandleBase::RunScript
4. **`$epsscript` 注入被实证为错误路线**（持续弹"模块未加载"）
5. **SSCore32实际基址0xf20000**（非IDA默认），已修正
6. **UI合成点击（WM_COMMAND）不等于真实用户路径**，常无法命中目标调用
7. **主线pipeline已可复现跑通**，支持全量函数/字符串拉取与高价值批量反编译

### 5.2 命令路由完整链路

```
用户输入 → WM_SETTEXT (Frida注入)
    → CSSView::OnCommandMsg
    → CSSView::OnEpsCommand           (0x12acf0a)
    → CSSView::CallBackFunction
    → CSSERPToolsInterface::OnCallBackMessage  (0xca6bdf0)
    → SSERPTools.OCB
    → [分流到各Handler]
```
