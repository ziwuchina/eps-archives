## 一、核心成果回顾

### 1. 加密机制(已 100% 验证)
| 项目 | 顺德狗 | 佛山狗 |
|---|---|---|
| 加密因子 | 18 / 60 / 11° / 9° | 45763 / 12846 / 10° / 20° |
| 加密标记 | `1ds1` | `1sf0` |
| 本质 | 坐标数学变换(非密码学),`X' = X·cos(θ) + 平移` | 同左 |

**终极转换公式**(反编译 TransEdbEF 还原,全库回环 68,171 点 0.000000 米误差):
```
Tmod = (616 + 月×576 + 日×384 + 时×256 + 分) % 1000   ← 要素 CreateTime 驱动
B    = (N×ID + Tmod) % 1000                            ← N=点数, ID=要素ID
X_佛山 = X_顺德 + 45745 + B×((i+1)%100)×(cos10°−cos11°)
Y_佛山 = Y_顺德 + 12786 + B×((i+1)%100)×(cos20°−cos9°)
```

### 2. EDBConvert 转换器(v7 当前版)
- 源码:`.workbuddy\tools\edb_convert_full.py`(pyinstaller --onefile --hidden-import pyodbc 打包)
- **退出码契约**(VBS/调用方按语义处理):
  | ExitCode | 含义 |
  |---|---|
  | 0 | 转换成功 |
  | 1 | 异常 |
  | 2 | F2S 遇顺德版(防呆,跳过转换直接打开) |
  | 3 | S2F 遇佛山版(防呆,跳过转换直接打开) |
  | 4 | 标记-坐标不一致(半转换错乱文件,拒绝) |
  | 5 | 坐标不在合理带(被多次转换,拒绝) |
- **三次模式**:无参数=用法+等待按键;单参数(拖拽)=自动 S2F;三参数(命令行)
- **注册表自注册**:启动时写入 `HKCU\Software\EDBConvert\InstallPath / ExePath`,根治路径定位

## 五、安全机制汇总

| 机制 | 说明 |
|---|---|
| 版本防呆 | F2S 遇 1ds1(exit=2)/ S2F 遇 1sf0(exit=3)拒绝 |
| 坐标带防呆 | 坐标不在顺德/佛山带 → exit=5 拒绝(多次转换) |
| 一致性防呆 | 标记与坐标矛盾 → exit=4 拒绝(半转换文件) |
| 备份链 | .bak(佛山原版)→ .sd_tmp(转换安全副本)→ 错乱双备份 |
| 失败回滚 | 保存失败自动从 .sd_tmp 恢复顺德版并重开工程 |
| 进程占用 | 保存流程先 CloseDatabase 再转换,避免文件独占 |
