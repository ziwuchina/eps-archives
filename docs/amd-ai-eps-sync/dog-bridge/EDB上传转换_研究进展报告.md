## 一、已攻克的三个关键突破

### 1. ✅ EDB 可用标准数据库驱动打开(pyodbc)

```
EDB 文件头 "Standard Jet DB" → 标准 Microsoft Jet 数据库
→ 用 pyodbc + "Microsoft Access Driver (*.mdb, *.accdb)" 直接读写!
→ 196 张表全部可访问:GeoAreaTB(面)、GeoLineTB(线)、GeoPointTB(点)、MarkNoteTB(注记)
```

### 2. ✅ 坐标存储位置确认

| 位置 | 说明 |
|---|---|
| **Graphics BLOB** | 图形坐标,格式:`2 字节点数 + 1 字节标志 + N×(X,Y double) + 14 字节尾部` |
| **MinX/MinY/MaxX/MaxY** | 包围盒(明文,**不随加密变化**,TransEdbEF 也不改) |
| **IniInfoTB.EncryptCoordMark** | 加密标记,顺德版值为 `b'1ds1'` |

### 3. ✅ 坐标变换规律破解(实测验证)

对 58610 个坐标点做拟合,确认变换为**平移 + 点序号项**(非角度缩放):

| 方向 | 公式(佛山 = f(顺德)) | 拟合精度 |
|---|---|---|
| X | +45745.47 + 0.4739·n | 线内残差 **0**(精确) |
| Y | +12778.85 − 7.15·n | 线内残差 **0**(精确) |

> n = 要素内点序号。**"线内精确、跨要素常数不同"** 是当前唯一未完全复刻的细节(需完整还原 TransEdbEF 的遍历计数逻辑,即反汇编中的 `(n+1)%100 × B` 公式)。
