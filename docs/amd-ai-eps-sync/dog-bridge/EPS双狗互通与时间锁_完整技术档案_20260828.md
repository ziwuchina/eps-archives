## 一、项目背景与目标

测绘公司持有两条加密狗：
- **顺德狗（旧）**：参数 18 / 60 / 11° / 9°，标记 `1ds1`
- **佛山狗（新）**：参数 45763 / 12846 / 10° / 20°，标记 `1sf0`

两版 EDB 数据互不兼容，核心诉求：
1. **打开**：顺德狗打开佛山下发数据 → 自动 F2S 转顺德版
2. **保存**：顺德狗绘制后交回佛山 → 自动 S2F 转佛山版，**文件名全程不变**
3. **上传自动化**：VBS 上传脚本 FileCopy 后自动转佛山版
4. **可迁移部署**：工具与 Eps.exe 同目录，相对路径，拷到其他电脑可用
5. **数据安全**：误操作能恢复、防呆检测、备份保障

## 二、加密机制破解（已 100% 验证）

- 加密本质：坐标数学变换（非密码学），`X' = X·cos(θ) + 平移`
- **终极转换公式**（反编译 TransEdbEF 还原）：
  ```
  Tmod = (616 + 月×576 + 日×384 + 时×256 + 分) % 1000   ← 要素 CreateTime 驱动
  B    = (N×ID + Tmod) % 1000                            ← N=点数, ID=要素ID
  X_佛山 = X_顺德 + 45745 + B×((i+1)%100)×(cos10°−cos11°)
  Y_佛山 = Y_顺德 + 12786 + B×((i+1)%100)×(cos20°−cos9°)
  ```
- 全库回环验证：68,171 点误差 0.000000 米；用户双转换对照实测"无差异"
- EDB 格式：标准 Jet 数据库（pyodbc + Microsoft Access Driver，196 张表），坐标在 `GeoAreaTB/GeoLineTB/GeoPointTB/MarkNoteTB` 的 Graphics BLOB
- 加密标记：`IniInfoTB.EncryptCoordMark` = `1ds1`（顺德）/ `1sf0`（佛山）

## 六、时间锁之谜（系统时间被改）

### 现象
每次启动顺德版 EPS（Eps.exe），系统时间被锁到固定值 `2026-09-19 22:18:30.000`，随后 W32Time 又按真实时间拨回，反复拉锯 → 用户看到"时间有规律乱跳"。

### 取证（Windows 事件日志 System / Kernel-General / Event ID 1）
- 修改者字段直接显示进程名 `Eps.exe`（多个实例）+ `svchost PID` = W32Time 服务
- 所有 Eps.exe 改的都是**同一个固定值** `22:18:30` → 代码写死的常量，非当前时间快照

### 根因（KeyMaker 读狗截图实锤）
顺德狗内有两个时间：
- `软件使用期限 2040/08/19`（界面顶部只读输入框）
- `加密锁时钟 2026-09-19 22:18:30`（信息框只读显示，**不提供修改入口**）

Eps.exe 启动时把系统时间**同步到狗的"加密锁时钟"**：用于时间相关的许可校验一致性、防改系统时间绕过校验、对齐数据 CreateTime 基准。

### 解决方案（已交付）

**方案 A：时间守护（纠正制，推荐）**
- `狗狗问题\时间守护\时间守护.exe`（customtkinter + pyinstaller，requireAdministrator manifest）
- 功能：禁止修改时间 / 恢复修改时间 / 重启电脑 / 关闭 / 开机自启开关 / 实时状态检测
- 原理：守护进程维护独立时间基线，每 1.5s 检查，偏移超 5s 自动改回（WMI `SetDateTime`，实测 ReturnValue=0 有权限）

**方案 B：禁止改时间（权限制，无条件拦截）**
- `狗狗问题\禁止改时间\禁止改时间.bat`：用 `secedit` 移除管理员组的 `SeSystemtimePrivilege`（仅保留 SYSTEM + Local Service）
- **关键陷阱**：Windows token 继承——改动只影响之后新建的进程。若 EPS 由早于策略修改就启动的旧进程（如 Maye Nano 启动器）拉起，会继承旧令牌而改时间失败无效 → **必须重启电脑 / 完全退出 Maye 重开 / 直接双击 Eps.exe**，新令牌才生效
- 用户实测：重启后时间不再被改 = 方案有效 ✓

> ⚠️ 360 时间保护器（360TimeProtect）已不适配 Win10/11，装驱动报"安装驱动服务失败"，不推荐。

## 七、EPS 授权钩子（IsRegister / IsRegisterSoft）

全网扫描命中：各工作空间 `Eps.ini` 以 `@~@` 换行内嵌 `IsRegisterScript`：

```vbs
Function IsRegister(softName, hardID, localizationMark, registrationCode)
   IsRegister = SSProcess.MapMethod( "IsRegisterSoft", softName)
End Function
```

- **命中文件**（仅扫描、未改动）：
  - EPS2020 副本：`DeskTop\` 下 佛山基础地形测绘(专网)/三维测图/佛山基础地形测绘(外网)/顺德联合测绘/顺德基础测绘（佛山版）/南海农房/存量房测绘 的 `Eps.ini`
  - EPS2016：`FS2K20260820\DeskTop\` + `FS2K20181118-E1022\DeskTop\房地一体` 共 8 处 `Eps.ini`
- **关键结论**：`IsRegister` 仅把 `softName` 透传给原生方法 **`SSProcess.MapMethod("IsRegisterSoft", softName)`**；`hardID / localizationMark / registrationCode` 三个参数**声明但未使用**；真正校验在 EPS 核心二进制读取加密狗/许可完成
- 每个脚本块上方有 `Password=...` + `SaveScript=1`（口令保护 ini 脚本）
- `SoftName` 按工作空间变化：`SScript`、`SSOblique`、`SSReTools` 等，代表该空间校验的模块许可
- **性质**：EPS 内置授权钩子，属软件许可机制，**不改动**（改动会破坏授权）
