### 4.2 COM 外部自动化通道验证成功
官方 demo（`进程外调用EPS_Demo.vbs`）揭示配方：
```vbs
Set epsApp = CreateObject("Eps.EpsApplication")
epsApp.SetVisible 1
Set SSProcess = epsApp.GetScriptDispatch("SScript.dll", "SSProcess")

SSProcess.CreateNewObjByCode / AddNewObjPoint / SaveBufferObjToDatabase
```
